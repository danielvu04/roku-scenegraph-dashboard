# roku-couch — shared spec

A Roku take on couch-tv (github.com/Seagey/couch-tv, MIT): an ambient dashboard **channel** on the Roku plus a **phone remote** served by a small **bridge** on an always-on computer (laptop, Pi). Target device: Roku Express 4K+ (Roku OS 12+), sideloaded in developer mode.

Not in scope (Roku can't do them): replacing the Roku home screen, a cross-app "keep watching" row.

## config.json (both parts read it)

```json
{
  "roku_ip": "",                 // empty => bridge auto-discovers via SSDP
  "bridge_port": 8787,
  "location": { "name": "Minneapolis", "lat": 44.98, "lon": -93.27 },
  "units": "fahrenheit",         // or "celsius"
  "clock_24h": false,
  "background_seconds": 45,
  "favorites": []                // optional list of Roku app IDs to pin first in the remote
}
```

The channel can't read files outside its package, so `roku-channel/tools/build` copies the relevant fields (location, units, clock_24h, background_seconds) into `roku-channel/source/config.json` (or a generated .brs) at build time. Falls back to defaults if config.json is missing.

## Roku channel (Agent A)

- SceneGraph, `ui_resolution=fhd`, works at 1920x1080.
- Full-screen rotating backgrounds (crossfade), bundled PNG/JPG gradients/abstract art **generated by a script** (Python + Pillow) — no third-party images.
- Large clock + date (updates every second via Timer node), respects clock_24h.
- Weather from Open-Meteo `https://api.open-meteo.com/v1/forecast?latitude=..&longitude=..&current=temperature_2m,weather_code&daily=temperature_2m_max,temperature_2m_min&temperature_unit=..&timezone=auto` fetched in a **Task node** (roUrlTransfer with `common:/certs/ca-bundle.crt`), refresh every 15 min, show current temp, condition text/icon from WMO code, today's hi/lo. Fail gracefully (hide widget, retry).
- Back button on the home scene exits the channel cleanly; no crashes on missing network.
- Screensaver-friendly: no burn-in — slowly drift clock position every few minutes.
- `tools/build.sh` produces `dist/roku-couch.zip` ready for upload at `http://<roku-ip>` (dev mode installer). Optional `tools/deploy.sh <ip> <dev-password>` uses curl digest auth to `/plugin_install`.
- Validate with BrighterScript (`npx brighterscript` / `bsc` with a bsconfig.json) — must compile with zero errors.

## Bridge + phone remote (Agent B)

Python 3.11+, **stdlib only** (http.server/ThreadingHTTPServer, urllib, socket). Serves the remote UI and proxies to Roku ECP on `http://<roku_ip>:8060` (browsers can't call ECP directly: no CORS, mixed content).

HTTP API (JSON):
- `GET  /api/status` → `{roku_ip, reachable, device: {name, model, power_mode}}` from `/query/device-info`
- `POST /api/key/{key}` → ECP `POST /keypress/{key}`; whitelist valid ECP keys (Home, Back, Select, Up, Down, Left, Right, Play, Rev, Fwd, InstantReplay, Info, Search, Enter, Backspace, VolumeUp, VolumeDown, VolumeMute, PowerOff, PowerOn, Power)
- `POST /api/text` body `{text}` → sends `Lit_<urlencoded char>` per character
- `GET  /api/apps` → list from `/query/apps` (id, name, type), favorites first
- `GET  /api/apps/{id}/icon` → proxy `/query/icon/{id}` (image passthrough, cache)
- `POST /api/launch/{id}` optional body `{contentId, mediaType}` → `/launch/{id}?...`
- `POST /api/dashboard` → launches the sideloaded channel (`/launch/dev`)
- `POST /api/search` body `{keyword}` → `/search/browse?keyword=..` (Roku's built-in global search)
- `GET /api/active-app` → `/query/active-app`
- SSDP discovery (`ST: roku:ecp`) when roku_ip empty; cache result; `--roku-ip` CLI override.
- Bind 0.0.0.0, no auth (LAN only) — README must warn: don't expose to internet; same caveat as couch-tv.
- Clear error JSON when Roku unreachable or ECP returns 403 (hint: Settings › System › Advanced system settings › Control by mobile apps › Network access → Permissive).

Phone remote (`bridge/static/`): single-page, no build step, mobile-first, dark theme, installable (manifest.json + icons). D-pad, OK, Back, Home, play/pause/rew/ffw, volume, power, keyboard text entry, search box, app grid with icons, "Dashboard" button, status pill. Haptic `navigator.vibrate` on press. Long-press repeat on d-pad.

Tests: `python3 -m unittest` in bridge/ against a fake ECP server (local http.server) covering each endpoint, whitelist rejection, text encoding, unreachable Roku.
