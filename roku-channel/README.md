# Couch Dashboard (Roku channel)

An ambient dashboard channel for Roku: full-screen crossfading backgrounds, a
large clock and date, and current weather from [Open-Meteo](https://open-meteo.com)
(no API key). Built for a Roku Express 4K+ (Roku OS 12+) at 1920x1080, but works
on any Roku that supports SceneGraph.

You install it by **sideloading** in developer mode. It is not in the Channel Store.

## What it does

- Background art changes every `background_seconds` with a 2.5 s crossfade. All
  images are generated by `tools/gen_assets.py`, so no third-party art is bundled.
- The clock updates every second and follows `clock_24h`.
- Weather refreshes every 15 minutes. If a fetch fails it retries with backoff
  (30 s, 1 min, 2 min ... up to 15 min). The last good reading stays on screen for
  up to an hour, then the weather block is hidden until a fetch works again.
- To avoid burn-in, the clock/weather block moves to a new spot every 3 minutes
  with a slow 12 s glide.
- Remote: **Back** exits. **Left/Right** (or Rew/Fwd) changes the background.
  **OK** (or Replay) refreshes the weather now.

## 1. Enable developer mode on the Roku

1. With the Roku remote, press **Home x3, Up x2, Right, Left, Right, Left, Right**.
2. The Developer Settings screen appears. Note the IP address it shows
   (e.g. `http://192.168.1.50`).
3. Choose **Enable installer and restart**, accept the SDK license, and
   **set a web server password**. The username is always `rokudev`.
4. The Roku restarts. Use the same sequence again later to change the password
   or turn developer mode off.

You can also find the IP under Settings > Network > About.

## 2. Configure

The channel reads the shared config at build time, because a channel can't read
files outside its own package. `tools/build.sh` looks for:

1. `../config.json` (your copy, gitignored)
2. `../config.example.json`
3. built-in defaults (Minneapolis, Fahrenheit, 12-hour clock, 45 s backgrounds)

It uses these fields: `location.name/lat/lon`, `units` (`fahrenheit` or `celsius`),
`clock_24h`, and `background_seconds` (kept between 10 and 3600). Out-of-range
values fall back to defaults. After you change the config, **rebuild and
re-upload**.

```bash
cp ../config.example.json ../config.json   # then edit it
```

## 3. Build

You need Python 3, Pillow (`python3 -m pip install Pillow`) and `zip`.

```bash
cd roku-channel
tools/build.sh            # writes dist/roku-couch.zip
tools/build.sh --assets   # also regenerates the images
```

The build:

1. generates `images/` if it's missing (or always, with `--assets`)
2. writes `source/generated_config.brs`
3. runs BrighterScript validation if you've run `npm install`
4. zips `manifest`, `source/`, `components/` and `images/` with the manifest at
   the root of the zip

Optional validation (Node 18+):

```bash
npm install
npx bsc --create-package false   # compile check, should report 0 errors
npx bslint                       # lint
```

## 4. Install

**Browser:** open `http://<roku-ip>` and sign in as `rokudev` with your password.
Choose `dist/roku-couch.zip` and click **Install** (or **Replace** if it's
already installed). The channel starts right away.

**Script:**

```bash
tools/deploy.sh 192.168.1.50 'your-dev-password'
# deploy: Install Success.
```

The sideloaded channel shows up on the home screen as **Couch Dashboard**. You can
also start it from the phone remote's "Dashboard" button (ECP `/launch/dev`).
Only one sideloaded channel can be installed at a time; uploading again replaces it.

## Keeping it on screen

- The Roku system screensaver can start over any channel that isn't playing
  video. To leave the dashboard up, go to Settings > Theme > Screensavers >
  Change wait time and pick the longest option, or turn it off if your Roku
  offers that.
- Some TVs have their own power-saving or auto-off timer. Turn that off in the
  TV's settings if the screen goes dark.
- The drift and slow background changes are there to reduce burn-in on OLED or
  plasma screens, but don't leave any static image up for days.

## Troubleshooting

| Problem | What to try |
| --- | --- |
| `deploy.sh` says upload failed / 401 | Wrong password or IP, or developer mode is off. Check that `http://<ip>` opens the installer page. |
| "Install Failure: Compilation Failed" | Run `npm install && npx bsc --create-package false` and fix what it reports. To see the device's own error output, run `telnet <roku-ip> 8085` while installing. |
| No weather | The Roku needs internet access to `api.open-meteo.com`. Check the lat/lon in config. Watch `telnet <roku-ip> 8085` for `WeatherTask:` lines. The block shows up after the first successful fetch. Press OK to retry now. |
| Wrong time | The clock uses the Roku's time zone: Settings > System > Time. |
| Wrong units, city or clock style | Edit `../config.json`, then rebuild and re-upload. The config is baked in at build time. |
| Backgrounds don't change | The `images/bg_*.jpg` files are missing. Run `tools/build.sh --assets`. |
| Channel exits right away | Open the debug console (`telnet <roku-ip> 8085`) and look for the BrightScript error and line number. |

Debug consoles: port **8085** shows BrightScript output and crashes, and port
**8080** is the developer console. Each SceneGraph thread prints to 8085.

## Layout

```
roku-channel/
  manifest
  source/main.brs                 screen + event loop
  source/generated_config.brs     build output (gitignored)
  components/HomeScene.xml/.brs   UI, clock, crossfade, drift, keys
  components/WeatherTask.xml/.brs Open-Meteo fetch (Task thread)
  images/                         generated art (backgrounds, icons, splash, weather icons)
  tools/gen_assets.py             Pillow art generator
  tools/gen_config.py             config.json -> generated_config.brs
  tools/build.sh, tools/deploy.sh
  bsconfig.json, bslint.json, package.json
```
