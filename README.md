# roku-couch

A Roku take on [couch-tv](https://github.com/Seagey/couch-tv) (MIT), which this
project credits for the idea. It has two parts:

- **[roku-channel/](roku-channel/README.md)**: a sideloaded Roku channel called
  "Couch Dashboard". It shows full-screen crossfading backgrounds, a large clock and
  date, and current weather from Open-Meteo (no API key needed). It's built for a
  Roku Express 4K+ on Roku OS 12+ at 1920x1080.
- **[bridge/](bridge/README.md)**: a small Python 3.11+ server that uses only the
  standard library. Run it on an always-on computer (laptop, Raspberry Pi). It
  serves a phone remote web app (D-pad, media and volume keys, typing, Roku search,
  an app grid, and a "Dashboard" button) and passes its commands to the Roku's
  External Control Protocol (ECP) on port 8060. The bridge is needed because a web
  page on your phone can't call ECP directly (no CORS, mixed content).

## What it can't do

Roku doesn't allow these, so they aren't included:

- **Replace the Roku home screen.** The dashboard is an ordinary channel. Open it
  from the home screen or with the remote's "Dashboard" button.
- **A cross-app "keep watching" row.** Channels can't see what you watched in
  other apps.

## Quick start

### 1. Config

```bash
cp config.example.json config.json
```

Edit `config.json`:

| Field | Used by | Meaning |
| --- | --- | --- |
| `location` (`name`, `lat`, `lon`) | channel | Place to show weather for |
| `units` | channel | `"fahrenheit"` or `"celsius"` |
| `clock_24h` | channel | `true` for a 24-hour clock |
| `background_seconds` | channel | Seconds between background changes (10 to 3600) |
| `roku_ip` | bridge | Leave empty to auto-discover the Roku over SSDP, or set it (e.g. `"192.168.1.50"`) |
| `bridge_port` | bridge | Port for the phone remote (default 8787) |
| `favorites` | bridge | Roku app IDs to show first in the app grid |

The channel copies its settings into the package at build time. After you change
them, rebuild and upload the channel again.

### 2. Turn on developer mode on the Roku

On the Roku remote, press **Home ×3, Up ×2, Right, Left, Right, Left, Right**. Then
choose **Enable installer and restart** and set a web server password. The
username is always `rokudev`. Write down the IP address that the screen shows.

### 3. Build and sideload the channel

You need Python 3, Pillow and `zip`.

```bash
cd roku-channel
tools/build.sh                                  # writes dist/roku-couch.zip
tools/deploy.sh <roku-ip> '<dev-password>'      # or upload it at http://<roku-ip>
```

Optional compile check: run `npm install`, then `npx bsc --create-package false`.
For troubleshooting, see [roku-channel/README.md](roku-channel/README.md).

### 4. Run the bridge

```bash
cd bridge
python3 couch_bridge.py                 # discovers the Roku automatically
python3 couch_bridge.py --roku-ip 192.168.1.50   # if discovery doesn't work on your network
```

To run it as a systemd service, see [bridge/README.md](bridge/README.md).

### 5. Open the remote on your phone

Connect your phone to the same Wi-Fi network. Open the URL the bridge prints, for
example `http://192.168.1.20:8787/`. To add it to your home screen:

- **iPhone (Safari):** Share › Add to Home Screen.
- **Android (Chrome):** menu › Install app.

## Tip: "403 Forbidden" / Roku refuses commands

Newer Roku OS versions limit ECP access. If the remote shows a 403 error, go to
**Settings › System › Advanced system settings › Control by mobile apps ›
Network access** on the Roku and set it to **Permissive**.

## Security

**The bridge has no authentication.** Anyone who can reach it can control your
Roku. Run it on your home network only. **Don't port-forward it or expose it to
the internet in any other way.** couch-tv has the same caveat. Roku's own ECP
has no authentication either, so the bridge doesn't add risk as long as it
stays on your LAN.
